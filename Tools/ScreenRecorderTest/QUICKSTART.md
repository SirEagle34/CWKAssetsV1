# 🎬 Screen Recorder Test App

## Inicio Rápido

```powershell
.\quick_test.ps1
```

Este script automáticamente:
1. Compila el APK
2. Instala en tu dispositivo
3. Ejecuta la app
4. Muestra logs en tiempo real

## Documentación Completa

Ver [README.md](README.md) para:
- Guía de uso detallada
- Modificación de parámetros
- Troubleshooting
- Integración a Unity

## Requisitos

- JDK 8+
- Android SDK (API 24-35)
- Dispositivo Android con USB debugging

## Primera Ejecución

La primera compilación puede tardar 1-2 minutos descargando dependencias. Las siguientes serán mucho más rápidas (15-30 segundos).
